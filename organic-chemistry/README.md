# Organic Nomenclature

A simple, black-and-white (well, off-white) static site that teaches IUPAC organic chemistry nomenclature: carbon-count prefixes, substituent (-yl) groups, functional group suffixes, an alkane reference table, common biological molecules, an animated molecule viewer, an interactive molecule builder, and a quiz.

**Live site:** https://tejas-ml.github.io/organic-chemistry/

## Run locally

No build step needed — just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```
