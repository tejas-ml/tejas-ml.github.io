# Orderbook

A lightweight, static web app featuring a virtual orderbook and an arbitrage view. Built with plain HTML, CSS, and JavaScript — no build step required. Includes light/dark theme support.

## Live Demo

👉 https://tejas-ml.github.io/orderbook/

## Pages

- **`index.html`** — Virtual Orderbook
- **`arbitrage.html`** — Arbitrage view

## Running Locally

Just open `index.html` in your browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
